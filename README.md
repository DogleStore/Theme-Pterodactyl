# Pterodactyl Modern UI & Expiration System
Custom modification for Pterodactyl Panel v1.11.x.

### Features
- **Modern Glassmorphism UI:** Neon accents, grid layout, and smooth transitions.
- **Expiration System:** Add `expired_at` date to servers with auto-suspension cronjob.
- **Automated Installer:** One-click installation and build process.

### Installation
Jalankan perintah ini sebagai root di folder Pterodactyl Anda:

```bash
bash <(curl -s https://raw.githubusercontent.com/jackdogle/Theme-Pterodactyl/main/install.sh)
